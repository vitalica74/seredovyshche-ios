# Середовище iOS v0.1.0
Перший експериментальний застосунок WKWebView з тестом IndexedDB. Не повний порт Android.

## На Mac
1. Встановити Xcode і XcodeGen (`brew install xcodegen`).
2. Виконати `xcodegen generate`, відкрити `Seredovyshche.xcodeproj`.
3. У Signing & Capabilities обрати власну Personal Team, за потреби змінити Bundle Identifier.
4. Під'єднати iPhone, вибрати пристрій і натиснути Run. Якщо Xcode попросить — увімкнути Developer Mode.

## Тест
Натиснути «Зберегти», повністю закрити застосунок, знову відкрити й натиснути «Прочитати». Записати результат, модель iPhone та iOS.

УВАГА: `file://` у WKWebView може обмежувати IndexedDB. Це навмисний тест; якщо не працює, наступний крок — стабільне походження для вебресурсів. Не зберігати реальні дані. Не видаляти застосунок під час тесту: його контейнер може бути втрачений.
